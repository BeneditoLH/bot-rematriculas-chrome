# Como contribuir

1. Descreva o problema e a forma de reproduzi-lo sem dados reais.
2. Faça mudanças pequenas, preservando as verificações de destinatário e o histórico de tentativas.
3. Execute `npm test` e descreva o resultado no pull request.
4. Atualize a documentação quando alterar configuração ou comportamento.

Não inclua planilhas preenchidas, telefones, nomes de pessoas, chaves, URLs de implantação ou logs de conversas. Use exemplos abstratos. Não teste enviando mensagens a terceiros sem autorização.
